# MachineLearning-F1

A Formula 1 machine learning project focused on:

* Data preprocessing
* Data visualization
* Classification
* Regression

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Project Structure

```bash
MachineLearning-F1/
│
├── preprocessing/
├── visualization/
├── classification/
├── regression/
├── dataset/
└── README.md
```

## Installation

```bash
git clone https://github.com/royakais/MachineLearning-F1.git
cd MachineLearning-F1
```

Install dependencies:

```bash
pip install -r requirements.txt
```
